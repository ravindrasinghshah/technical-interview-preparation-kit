## Programming Fundamentals

- Choose clear, descriptive variable and function names.
- Understand primitive values, references, arrays, objects and strings.
- Know how to iterate, break and skip values, and avoid unnecessary work.
- Use the appropriate return value for functions instead of only printing results.
- Consider input constraints before choosing a data structure or algorithm.
- Validate assumptions with small examples and edge cases.

## Suggested revision approach

1. Review the [math helpers](./maths.md) and JavaScript-specific pitfalls.
2. Read the [revision notes](./revision-notes.md) once to recognize common patterns.
3. Practice one problem from each topic in [revision problems](./revision-problems.md).
4. Revisit the notes for patterns that feel unfamiliar.
5. Repeat difficult problems without looking at your previous solution.

## Problem-Solving Checklist

Before coding:

- [ ] Restate the problem in your own words.
- [ ] Identify inputs, outputs and constraints.
- [ ] Ask clarifying questions and define edge cases.
- [ ] Work through a small example by hand.
- [ ] Describe a brute-force approach first.
- [ ] Identify the bottleneck and an optimization.

While coding:

- [ ] State the approach and its invariant.
- [ ] Use standard JavaScript methods and data structures appropriately.
- [ ] Avoid unnecessary mutations unless the problem requires them.
- [ ] Add guard cases for empty or invalid inputs when appropriate.

After coding:

- [ ] Test normal, minimum, maximum and edge-case inputs.
- [ ] Check for off-by-one errors.
- [ ] State the time and space complexity.
- [ ] Look for a simpler implementation or a clearer invariant.
